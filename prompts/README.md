# Prompts

Every prompt your component sends, one file per prompt and version, from L01.

- **A prompt is code.** Change it in a pull request, and say in the
  description what the change did to the error rate on `evals/`.
- **Name the strategy in the file name:** `route_zero_shot.md`,
  `route_five_shot.md`, `route_cot.md`.
- **Never edit a prompt that produced a published figure.** Copy it to a new
  version, so every number in `docs/` can be traced to the exact text behind it.
