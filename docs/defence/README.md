# Defence

The slides of the oral defence (L06), as a PDF, committed before the session
starts: this is the file shown on the screen.

- File name: `slides.pdf`
- Ten minutes, every member speaking. The outline, from project step 5: the task
  and the users (1 min), how it works (2 min), how well and at what cost (3 min),
  how it fails and how it resists misuse (2 min), the recommendation (1 min).
- Every number on a slide says where it comes from: how many cases, which model,
  which day (`docs/evaluation.md`, `runs/eval/`).
- No live demo: a captured run from `runs/` instead.
