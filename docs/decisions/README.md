# Decision records

A decision record captures **one** decision: the context, the options, the
choice and its consequences. It fits on one page.

- **A record is never rewritten.** A later decision that changes it gets a new
  record that supersedes it, and the old one's status says so.
- **Number them in order:** `0001-component-and-task.md`, `0002-...`.
- **Start from** [`0000-template.md`](0000-template.md).
- **Every group member writes at least one** during the course.

The format follows Michael Nygard's "Documenting Architecture Decisions" (2011),
with two sections added for this course: the options considered and the
criteria.
