# Evaluation

Test cases from L01, the golden set and the evaluation report from L04.

- **A test case has a known right answer, checked by a person.** A set
  labelled by a model and scored by a model measures how much two models
  agree, not whether either is right.
- **Keep the cases you measure on separate from the examples in your prompts.**
  A few-shot example that is also a test case inflates the score.
- **Record every run:** the prompt file, the model, the date, the parameters,
  the error rate, the tokens and the cost. A run that is not recorded did not
  happen.
